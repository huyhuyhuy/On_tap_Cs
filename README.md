# Ôn tập C#

Repo ôn trắc nghiệm C# từ HTML Sanfoundry.

- `Collected_data/` — JSON câu hỏi (917 câu, 11 chủ đề)
- `pwa/` — PWA tĩnh (Vite + React), tiến độ lưu `localStorage`
- `scripts/` — extract HTML và copy dữ liệu vào PWA

Chạy app và deploy Cloudflare Pages: xem [pwa/README.md](pwa/README.md).
